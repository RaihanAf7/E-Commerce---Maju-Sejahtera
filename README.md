# 🛒 E-Commerce Website Statis

Proyek website e-commerce statis sederhana yang dirancang dengan tampilan modern, responsif, dan terstruktur rapi. Proyek ini dibuat untuk memenuhi kebutuhan latihan serta **Tugas Mata Kuliah Pemrograman Web 1 Universitas Pamulang (UNPAM) Kampus Serang**.

---

## ✨ Fitur & Komponen Utama
* **Header & Navbar:** Bagian navigasi utama dengan menu Beranda, Produk, Tentang, dan Kontak.
* **Banner Sambutan:** Kotak (*box card*) ucapan selamat datang dengan tata letak dan warna yang kontras.
* **Katalog Produk:** Menampilkan pilihan produk unggulan (Macbook, Monitor, Keyboard, Headphone) menggunakan **CSS Grid**.
* **Tentang & Kontak:** Bagian informasi profil singkat dan kontak pengembang/toko.
* **Footer:** Bagian penutup halaman web.

---

## 🛠️ Teknologi yang Digunakan
* **HTML5** (Struktur markup semantik)
* **CSS3** (Styling kustom, Flexbox, dan CSS Grid)

 🚀 Cara Menjalankan Proyek
1. Clone repository ini atau unduh (download) sebagai file ZIP.
2. Buka folder proyek menggunakan text editor (disarankan menggunakan Visual Studio Code).
3. Jalankan file index.html menggunakan ekstensi Live Server di VS Code, atau buka langsung file index.html melalui browser web pilihan Anda.
